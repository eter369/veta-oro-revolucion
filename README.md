# Rama `datos` · historial publicado por MIROFISH

La escribe GitHub Actions en cada corrida (`.github/workflows/pages.yml`, paso «Guardar historial en la rama datos»).
No se edita a mano. Contiene los JSON de `mirofish/datos/`: bitácora de señales, RR25 de Deribit, netflows,
liquidaciones de OKX, calendario macro y S&P/DXY. El generador y la bitácora la leen como respaldo
cuando kippuu.com no responde, y nunca escriben un historial más corto que el que leyeron.
